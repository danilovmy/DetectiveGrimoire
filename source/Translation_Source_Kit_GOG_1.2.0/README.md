# Самостоятельное применение перевода

Набор подготовлен для **GOG Detective Grimoire 1.2.0** (game ID `2087170042`, build ID `55081706531997481`).

В папке находятся:

- `translations_ru.xlsx` — русский перевод без исходных литературных текстов игры;
- `apply_translation.py` — основной Python-скрипт;
- `scale_text.py` — пропорционально уменьшает буквы и межбуквенные смещения;
- `apply.ps1` — удобный запускатор, который сам скачает Java и FFDec при первом запуске;
- `extract_texts.py` — извлекает карту строк из локально установленной игры.
- `fill_originals.py` — по запросу создаёт локальную копию XLSX с английскими оригиналами.
- `wrap_static_text.py` — переносит длинный статический текст по словам внутри границ исходного поля.

## Требования

- Windows;
- Python **3.10 или новее**: проверьте командой `python --version`;
- интернет на первом запуске, чтобы `apply.ps1` скачал Java 21 и JPEXS Free Flash Decompiler;
- установленная GOG-версия игры 1.2.0.

Для готового русификатора Python не требуется — он нужен только для самостоятельной повторной сборки из XLSX.

## Как применить изменённый перевод

1. Закройте игру.
2. Откройте PowerShell в этой папке.
3. Выполните команду, заменив путь после `-GameDir` на папку с `Detective Grimoire.exe`:

   ```powershell
   .\apply.ps1 -GameDir "D:\Games\Detective Grimoire" -Translations .\translations_ru.xlsx
   ```

По умолчанию используется Comic Sans, а размер и межбуквенные смещения уменьшаются до 50%. Длинные статические надписи дополнительно переносятся на следующую строку по границе поля, без разрыва слов. Перед заменой скрипт сохранит изменяемые SWF в `localization\backups` внутри папки игры. Отключить переносы для диагностики можно параметром `-NoWordWrap`.

Чтобы сначала только проверить входные файлы, добавьте `-DryRun`.

## Важно

Не меняйте столбец `Ключ` в XLSX: он связывает перевод с нужными надписями игры. Перед применением скрипт извлечёт техническую карту тегов только из локальной папки игры и сохранит её рядом с игрой; в набор и репозиторий она не входит.

## Как посмотреть оригиналы

Исходные литературные тексты игры — диалоги, реплики и описания — намеренно не публикуются в репозитории. Поэтому файл `translations_ru.xlsx` содержит только русский перевод, а колонка `Оригинал` пуста. Чтобы посмотреть оригиналы в отдельной локальной копии XLSX, сначала создайте карту строк без изменения игры:

```powershell
.\apply.ps1 -GameDir "D:\Games\Detective Grimoire" -Translations .\translations_ru.xlsx -DryRun
```

Затем создайте отдельную копию таблицы с оригиналами:

```powershell
python .\fill_originals.py --workbook .\translations_ru.xlsx --catalog "D:\Games\Detective Grimoire\localization\catalog\occurrences.jsonl" --output .\translations_ru_with_originals.xlsx
```

`translations_ru_with_originals.xlsx` остаётся только на вашем компьютере. Не добавляйте его в публичный репозиторий.
